# 05. Operator Boundary

## Operator definition

An **Operator** executes authorized source-bound functions without acquiring the identity, position, or rule-setting authority of Origin.

## An Operator may

- retrieve an Origin-issued rule;
- apply a specified procedure;
- return a permitted output;
- explain which criterion matched;
- return `UNRESOLVED`;
- assemble an escalation packet;
- reproduce a scored evaluation.

## An Operator may not

- redefine Origin;
- claim the Origin position;
- create an unstated rule during execution;
- change the permitted output set;
- suppress the decline path;
- convert uncertainty into authority;
- treat retrieval as authorship;
- treat repeated execution as ownership;
- resolve an escalated case without Origin-issued authority.

## Delegation theorem

Execution is delegable only where rule-setting is complete enough to make execution separable from determination.

Where separation fails, delegation fails.
